# Persistent Project Rules

- Product: Universal Code Studio.
- Hosting target: GitHub Pages.
- Architecture: static Vite + React + TypeScript.
- Default mode: local-first, no account, no backend, no paid API.
- Every tool must clearly state its supported formats and operations.
- Hardware features are optional modules and must be feature-detected.
- Permissions are requested only after a user action.
- No automatic NFC/RFID writes.
- No protected credential extraction or access-control bypass.
- Never fabricate hardware results.
- Preserve raw bytes when parsing structured formats.
- Use BigInt for values wider than JavaScript's safe integer range.
- Add fixtures and tests for every format implementation.
- Keep user-facing language concise, plain and specific.
- Read the relevant docs before implementing a feature.
